# 面部与真实摄影标准

适用于薄肌感男生修图 Skill（Lean Muscle Photo Glow-Up）v2.0.1。本文件放**专业处理规则**；实际任务范围、调用工具、验收与返修由 `SKILL.md` 决定。相关规则必须在首次编辑时应用，而不是失败后补救。局部任务只适用于允许修改的区域。

## 一、活人感与身份底线（所有完整修图必读）

| 要素 | 处理规则 | 失败征象 |
| --- | --- | --- |
| 身份及神态 | 保留五官骨相、原眼神、嘴角位置、微表情、面部张力和自然不对称，脸更上镜仍能一眼认出本人 | 五官重排、统一对称、微笑变僵、眼神换人 |
| 真实皮肤 | 保留符合原片分辨率的毛孔、浅纹理、肤色细微差异、毛发与皮肤自然起伏；局部去瑕疵须与周围质地连续 | 大面积无孔磨皮、蜡像、高频假毛孔、皮肤一块光一块粗 |
| 反光和汗水 | 皮肤自然哑光至符合现场的轻微真实反光；原片已有汗珠、水滴、局部强高光按场景保留 | 额头、鼻梁、肩胸、手臂出现大面积统一油亮的健美海报质感 |
| 原片成像 | 人物、衣料、环境沿用同一光源、色温、曝光逻辑、景深、锐度差异及合理颗粒 | 脸比身体锐很多、人物棚拍式发光、背景被整体重造 |
| 自然色彩 | 延续原片白平衡、真实肤色和环境固有色，肌肉明暗变化仍属于同一现场光线 | 肤色增白或偏橙粉、背景和衣物异常鲜艳、塑形后全图被统一增艳 |

**活人感不是保留所有缺陷。** 可减轻影响观感的皱纹和疲态，也可让肌肉更饱满；要求是处理之后仍保留可信的人体纹理、自然表情和摄影证据。无须给照片主动增加假噪点、油光、皱纹或新毛孔。

**塑形后的皮肤仍以原片为依据。** 肌肉轮廓变化不应同时抹去局部肤色差、可辨认的小印记、毛发和自然受光不均。原片细节有限或人物较小时，接受其自然柔软度，不重建一层均匀、高清的假毛孔/毛发纹理。把新增体积与皮肤表现分开验收：形体改善但皮肤更像渲染或磨皮，仍判该项缺陷；恢复真实感不能只给整张图叠颗粒或锐化。

## 二、面部自然美化（面部可见且未锁定时）

**皱纹与疲态：** 按本图严重程度减轻明显抬头纹、眉间纹、法令纹、眼角细纹、眼下疲态与临时瑕疵。尤其是明显额纹，首轮就主动处理；目标是视觉上明显改善，周围自然渐变。不能整片磨平额头、抹除表情运动线索或把法令纹改成更深的假阴影。对于状态已好的部位不刻意重塑。

**颜值与轮廓：** 依原光源提升眉眼精神、眉骨/鼻梁/颧骨/面颊光影转折，适度整理下颌与面部整体上镜协调度。保留骨相、五官内部距离、表情与原有个体特征；不靠极端瘦脸、缩鼻、放大眼睛或统一磨皮制造模板化帅脸。

**头发与发际线：** 自然整理额角稀疏、局部凌乱或蓬松度；保留原发型、发流、自然发根、细碎发。未提出染发或换发型时不主动改变。

**头肩关系：** 先通过肩部自然饱满度与体态协调改善视觉比例，必要时才轻调头部整体相对大小；五官内部结构和颈肩连接不变，不骤缩头、不强拉腿长或变更相机透视。

**可观察的达标表现：** 皱纹或疲态有本图对应的改善；本人仍像本人；眉眼及面颊有自然神采；近看仍有细纹理、细发丝与面部微表情。面部不可见、分辨率不足或严格锁定时标记不适用。

## 三、摄影风格与原片保护

**默认保留原片质感与自然色彩。** 记录并延续：光源方向、白平衡、肤色与环境色关系、亮暗关系、皮肤反光、曝光特征、锐度与对焦差异、轻微颗粒噪点及自然景深。塑形、皮肤纹理和色彩分别判断；增强体积不默认附带调色或风格化。

**自然色彩的具体处理：**

- **基准与白平衡：** 原始照片是自然色彩基准；用户另有认可的颜色参考时按其指定。观察皮肤与画面中可用的中性色、环境光是否一致，只纠正明确偏色，不自动全图变暖、提白或改成清透滤镜。原片本身的明显问题可以适度纠正，不照搬失真。
- **肤色与肌肉层次：** 保留本人肤色和局部红润、晒痕等真实差异，不统一漂白、涂粉或加橙；新增肌肉曲面沿原光源形成柔和明暗，不靠加深饱和阴影、强局部对比、压黑肤色来显壮。人物和周围人的受光、亮度与色温须可信。
- **环境与衣物饱和度：** 保留物体原有色相和自然鲜艳程度，不因突出主体而全图提高饱和度或鲜艳度。橙红背景、蓝绿衣物、植被、水面等强色区域若异常抢眼，按与原片的差异局部回调；不套固定降饱和数值，也不把原本鲜艳的实物一律压灰。
- **验收与返修：** 在相近显示尺度下分别看肤色、中性色及强色物体；出现新增偏色、过艳、漂白或颜色断层，即使形体满意也判色彩项缺陷。优先保留已认可的形体，仅修色彩；单纯全图降饱和、叠颗粒或降低清晰度不等于恢复自然感。

以下为有明确风格需求时的可选参考，不作为默认增艳或滤镜指令：

- **浓郁层次（徕卡参考）**：加强明暗层次和主体体积，暗部保留细节，不把肤色推成橙红。
- **柔和中间调（哈苏参考）**：肤色干净、过渡细腻，既保留真实皮纹，也不把面部打成无影平光。
- **清透胶片（富士参考）**：高光柔和，适量自然颗粒与通透感，不强制增加噪点。

这些是**用户指定或本图确有收益时**的审美参考，不是按地点自动套品牌滤镜。日常抓拍保留日常感；海边、旅行、建筑和街拍中环境常属于叙事主体，不能为了突出人物自动抹掉背景。

**景深：** 默认维持原景深。只有用户要求，或背景干扰明显且距离、透视和场景叙事允许时，才选择合理的轻度渐进虚化；保持发丝、肩臂、衣物边缘和镜中反射的真实空间关系。不声称改变镜头物理焦段，不新建主光或重新设计机位。

## 四、真实性错误速查（供验收与返修）

- **表情失真：** 眼神、嘴角、眉毛表情和面部张力与本人差异明显 → 还原身份特征，再小幅局部美化。
- **去皱未达标：** 适用的明显额纹、眉间纹等几乎未改善 → 只对纹路/疲态做渐变修正，保护毛孔及周围纹理。
- **数字人感：** 脸部或身体过度平滑、均匀光亮、五官对称化 → 恢复可信的纹理和自然光影，不用人工乱点填充假毛孔。
- **摄影失真：** 人像比背景锐利/油亮很多、肤色与环境光不一致、虚化边缘假 → 回归原片色温、空间和层次。
- **色彩失真：** 形体改善但肤色漂白/偏橙粉、衣物或背景过艳、阴影颜色过重 → 对照原片分别回调白平衡、局部饱和度及对比，保留已认可形体，不以全图压灰代替修正。
- **误伤场景：** 衣服文字、Logo、镜面、手机、手指或背景构造受损 → 以原图对应部分修正；无可靠修复能力如实报告。
